## Run the Front-End

Open `index.html` in a browser, or use VS Code Live Server.

## Backend Integration

The Java backend can later expose endpoints such as:

- `POST /api/login`
- `GET /api/announcements`
- `GET /api/events`
- `GET /api/locations`
- `GET /api/support-services`
- `POST /api/feedback`

The front-end can then replace the sample data with API calls.
