# How Ujen Creates the Shared GitHub Repository

## Step 1 — Create the online repository
1. Sign in to GitHub.
2. Click **New repository**.
3. Repository name: `smart-campus-support-application`
4. Choose **Private** unless your lecturer requires Public.
5. Create the repository.

## Step 2 — Upload this starter repository
### Easy method
1. Extract `Smart_Campus_GitHub_Repository_Starter.zip`.
2. Open the new GitHub repository.
3. Choose **Add file > Upload files**.
4. Upload the files and folders from the extracted repository.
5. Commit the upload.

### Better method with GitHub Desktop
1. Install/open GitHub Desktop.
2. Add the extracted `smart-campus-support-application` folder.
3. Publish it to GitHub.

Before starting work, pull the newest files.
Commit changes with simple messages such as:
- `Add scope statement`
- `Update risk register`
- `Add database schema`
- `Update desktop wireframe`
- `Add login page`

Use Pull Requests to merge reviewed work into `main`.
